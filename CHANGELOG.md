# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [semantic versioning](https://semver.org).

## [1.0.0] - 2026-11-09

### Added

- First public release: a countdown to one date in the menu bar, shown as days, minutes or a ticking clock.
- Launch at Login, switched on the first time it opens.
- Builds for both Apple silicon and Intel Macs.
- README, AGENTS.md for AI coding tools, privacy notes, tests of the countdown rules, a CI check and an MIT license.
